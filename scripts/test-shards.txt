# Which CI job runs which of the workspace's test targets. scripts/test-shards.py
# reads this; each `[name]` starts a shard, and each line under it is one unit:
#
#   lib            every library's unit tests (cargo test --lib)
#   bins           every binary's unit tests (cargo test --bins)
#   doc            every library's doctests (cargo test --doc)
#   examples       every example builds (cargo build --examples), as a plain
#                  cargo test checks
#   test <name>    one integration test, tests/<name>.rs (cargo test --test <name>)
#
# Every unit belongs to exactly one shard, and a test target in no shard fails
# CI: give a new tests/*.rs a line here. The shards are balanced by how long
# their tests take on a CI runner (about seven minutes each); the crash suite
# has a job of its own.
