# Test helpers outside crates/<c>/tests/ that the controls rows' tests share,
# one per line, with the rows each serves:
#
#   <path>: --test             every row with a --test target
#   <path>: feature=<name>     every row whose --features turn <name> on
#
# A change to a helper listed here touches those rows, so CI's Controls
# workflow runs them (scripts/controls-touched.py). A helper that is not
# there, or a line that cannot be read, fails the workflow's plan.
