Searching our docs with findit misses documents it should find. A query with accents or capitals, such as Café, résumé or Straße, finds nothing, although cafe and resume do find documents that are written Café and résumé. Quoted phrases that contain a stopword, such as "point of sale" or "state of the art", never match, and the unquoted word state-of-the-art finds nothing either. Try them with: python3 -m findit --docs docs 'Café'. README.md says how queries must behave; make findit follow it, for every kind of query, without changing how documents are indexed or ranked. Run the tests with: python3 -m unittest discover -s tests -t .
